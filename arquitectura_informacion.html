C — Category (Categoría) Clasificación tripartita de celdas (voidCell, emptyHole, occupiedPeg) y estado binario de partida (Victoria vs. Finalizado). enum CellType • GameRecord.isVictory Diferenciación cromática e iconográfica instantánea (Trofeo verde para victoria vs. Reloj rojo para bloqueo).

COMPORTAMIENTO DINÁMICO // FSM & HARDWARE Ciclo de Vida de Interacción Táctil, Validación Ortogonal y Reinicio Físico por Acelerómetro
FSM // PegSolitaireViewModel
Flujo Determinista de Estados ante Eventos Táctiles (onCellTapped)
Latencia < 100ms (RNF-02)

ESTADO 01: IDLE

selectedPosition == null. Tablero en espera. Al pulsar una celda con occupiedPeg, reproduce playSelection() y transiciona a SOURCE_SELECTED.

ESTADO 02: SOURCE_SELECTED

La ficha origen brilla con borde ámbar (isSelected: true). Si el usuario pulsa la misma ficha, se cancela la selección y regresa a IDLE.

ESTADO 03: VALIDACIÓN ORTOGONAL

Al pulsar un emptyHole en to, _isValidMove(from, to) verifica: (Δrow == 2 && Δcol == 0) || (Δrow == 0 && Δcol == 2) y que la celda intermedia sea occupiedPeg.

ESTADO 04: EJECUCIÓN ATÓMICA

_executeMove vacía from y middle, ocupa to, decrementa remainingPegs, incrementa moveCount, agrega MoveRecord y dispara playJump().

ESTADO 05: EVALUACIÓN TERMINAL

_evaluateGameTermination() escanea las 4 direcciones. Si no quedan saltos válidos, activa isGameOver = true, evalúa isVictory (pegs == 1) y persiste en JSON.

PIPELINE DE HARDWARE // ACELERÓMETRO
Flujo de Reinicio por Sacudida Física (ShakeDetectorService)
  • Paso 1: CapturauserAccelerometerEventStream() emite (x, y, z)
  • Paso 2: Norma Euclidianaacceleration = sqrt(x² + y² + z²)
  • Paso 3: Filtro Umbralacceleration > 10.0 m/s²
  • Paso 4: Ventana Anti-ReboteΔt > 1200 ms desde última sacudida
  • Paso 5: Guardia de Dominioif (viewModel.isGameOver) → initializeBoard()
  • Paso 6: Notificación VisualSnackBar('¡Tablero reiniciado por movimiento físico!')
PIPELINE DE EXPORTACIÓN // SHARE SHEET
Captura de Lienzo y Uso compartido en OS (ScreenshotService)
  • Paso 1: Envoltura de RenderRepaintBoundary(key: _boardBoundaryKey)
  • Paso 2: Rasterizaciónboundary.toImage(pixelRatio: 2.0)
  • Paso 3: Codificación BinariatoByteData(format: ImageByteFormat.png)
  • Paso 4: Escritura TemporalgetTemporaryDirectory()/peg_solitaire_*.png
  • Paso 5: Intent del SistemaSharePlus.instance.share(ShareParams(files, text))
